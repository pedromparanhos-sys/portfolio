Fundamentos de StateGraph

Cinco notebooks constroem, um conceito por vez, o vocabulário do LangGraph: estado tipado, nós, arestas simples, roteamento condicional e laços controlados.

Graph I

Hello World

Primeiro grafo: um único nó que lê e transforma o estado, do START ao END.

Graph II

Múltiplas entradas

Estado com vários campos (values, name) processados em um mesmo nó.

Graph III

Agente sequencial

Encadeamento de dois nós, cada um lendo e ampliando o resultado do anterior.

Graph IV

Roteamento condicional

add_conditional_edges decide entre soma e subtração a partir do estado.

Graph V

Laços

Um nó reentra em si mesmo até uma condição de parada baseada em contador.

03

Agentes de IA

O módulo principal do curso: cinco agentes completos, cada um introduzindo um padrão de arquitetura diferente sobre GPT-4o.

Agent Bot

Agent_Bot.py

Chatbot conversacional simples: mantém o histórico da sessão em memória e grava a conversa completa em logging.txt ao final.

StateGraphhistórico de conversa

Memory Agent

Memory_Agent.py

Variante enxuta com foco em manter contexto entre turnos, base para os padrões de memória usados nos agentes seguintes.

memória de curto prazoHumanMessage / AIMessage

ReAct Agent

ReAct.py

Agente com tool calling: decide sozinho quando chamar ferramentas de soma, subtração e multiplicação, alternando entre modelo e ToolNode até resolver a tarefa.

ToolNodeconditional edgespadrão ReAct

Drafter

Drafter.py

Assistente de redação com humano no loop: atualiza um documento em memória a partir de instruções e só encerra o grafo quando o usuário confirma o salvamento em .txt.

human-in-the-loopupdate / save tools

RAG Agent

RAG_Agent.py

Pipeline completo de Retrieval-Augmented Generation: carrega e fragmenta Stock_Market_Performance_2024.pdf, indexa os trechos em uma vector store ChromaDB e responde perguntas citando as partes específicas do documento usadas.
